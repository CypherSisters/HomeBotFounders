# Encryption -- vault DEK (AES-256-GCM), PBKDF2-HMAC-SHA256 / scrypt key
# derivation, and the app-data log envelope. No X.509, no PKCS#7/CMS, no cert-chain
# verification anywhere in this tree.
#
# The floor is 48.0.1, not 41.0.0: every wheel below it statically links an
# OpenSSL predating the 2026-06-09 secadv (GHSA-537c-gmf6-5ccf), which is the
# one advisory that applies regardless of which APIs you call. 49.0.0 and
# 50.0.0 additionally close PYSEC-2026-3554/3553 (X.509 name-constraint escape,
# path-building DoS) and PYSEC-2026-3552 (PKCS#7 EnvelopedData decrypt oracle) --
# unreachable here, but taken anyway because nothing costs us to take them.
#
# The range resolves to 50.0.1 on every platform that publishes a wheel for it,
# including the Orin (cp39-abi3 manylinux2014_aarch64, cp310-compatible). Only
# 32-bit Windows and Intel macOS have no 49+/50+ wheel and land on 48.0.1.
# DO NOT lower the floor without re-checking the advisories above.
